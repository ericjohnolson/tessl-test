# Task: TDD with ZOMBIES Heuristic

Using TDD, implement a `BoundedQueue` with a fixed capacity (FIFO):

- `BoundedQueue(capacity)` — creates a queue with the given max capacity
- `enqueue(item)` — adds item to the back (error if full)
- `dequeue()` — removes and returns the front item (error if empty)
- `size()` — returns the current number of items
- `isFull()` — returns true if at capacity
- `isEmpty()` — returns true if no items

Apply the ZOMBIES heuristic explicitly when planning your tests. Use the TDD skill.
