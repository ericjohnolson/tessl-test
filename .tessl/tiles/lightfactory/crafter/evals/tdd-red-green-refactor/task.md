# Task: TDD Red-Green-Refactor Cycle

Using TDD, implement a `Stack` class (or module) with the following operations:

- `push(item)` — adds an item to the top
- `pop()` — removes and returns the top item (error if empty)
- `peek()` — returns the top item without removing it (error if empty)
- `isEmpty()` — returns true if the stack has no items

Use the TDD skill. Follow strict red-green-refactor discipline.
